# 28. I/O and NIO

### Classic I/O (java.io)

```java
// Reading a file
try (BufferedReader reader = new BufferedReader(new FileReader("file.txt"))) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
}

// Writing a file
try (BufferedWriter writer = new BufferedWriter(new FileWriter("file.txt"))) {
    writer.write("Hello, World!");
    writer.newLine();
}

// Byte streams
try (InputStream in = new FileInputStream("data.bin");
     OutputStream out = new FileOutputStream("copy.bin")) {
    in.transferTo(out);  // Java 9+
}
```

### NIO.2 (java.nio — Modern File I/O)

```java
import java.nio.file.*;

// Path (like C# System.IO.Path)
Path path = Path.of("src", "main", "java", "App.java");
Path home = Path.of(System.getProperty("user.home"));
Path absolute = path.toAbsolutePath();
Path parent = path.getParent();
String fileName = path.getFileName().toString();

// Reading files (convenience methods)
String content = Files.readString(Path.of("file.txt"));
List<String> lines = Files.readAllLines(Path.of("file.txt"));
byte[] bytes = Files.readAllBytes(Path.of("data.bin"));

// Writing files
Files.writeString(Path.of("file.txt"), "Hello!");
Files.write(Path.of("file.txt"), lines);
Files.write(Path.of("file.txt"), "append".getBytes(), StandardOpenOption.APPEND);

// File operations
Files.copy(source, target, StandardCopyOption.REPLACE_EXISTING);
Files.move(source, target, StandardCopyOption.ATOMIC_MOVE);
Files.delete(path);
Files.deleteIfExists(path);
Files.createDirectory(path);
Files.createDirectories(path);  // like mkdir -p

// File information
boolean exists = Files.exists(path);
boolean isDir = Files.isDirectory(path);
long size = Files.size(path);
FileTime modified = Files.getLastModifiedTime(path);

// Walking directory tree
try (Stream<Path> walk = Files.walk(Path.of("src"))) {
    List<Path> javaFiles = walk
        .filter(p -> p.toString().endsWith(".java"))
        .toList();
}

// List directory contents
try (Stream<Path> list = Files.list(Path.of("."))) {
    list.forEach(System.out::println);
}

// Find files matching pattern
try (Stream<Path> found = Files.find(Path.of("src"), 10,
        (path2, attrs) -> path2.toString().endsWith(".java"))) {
    found.forEach(System.out::println);
}
```
