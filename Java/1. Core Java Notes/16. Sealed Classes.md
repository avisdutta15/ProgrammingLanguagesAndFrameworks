# 18. Sealed Classes

Sealed classes (Java 17+) restrict which classes can extend them — like C# `sealed` but more flexible.

```java
// Only Circle, Rectangle, and Triangle can extend Shape
public sealed class Shape
    permits Circle, Rectangle, Triangle {

    // common shape code
}

// Permitted subclass options:
public final class Circle extends Shape { }        // final — no further extension
public sealed class Rectangle extends Shape        // sealed — restricted further
    permits Square { }
public non-sealed class Triangle extends Shape { } // open — anyone can extend

public final class Square extends Rectangle { }
```

### Sealed Interfaces

```java
public sealed interface Expression
    permits Constant, Addition, Multiplication {
}

public record Constant(double value) implements Expression { }
public record Addition(Expression left, Expression right) implements Expression { }
public record Multiplication(Expression left, Expression right) implements Expression { }
```

### Use with Pattern Matching

```java
// Exhaustive switch (compiler knows all subtypes)
double evaluate(Expression expr) {
    return switch (expr) {
        case Constant c -> c.value();
        case Addition a -> evaluate(a.left()) + evaluate(a.right());
        case Multiplication m -> evaluate(m.left()) * evaluate(m.right());
        // No default needed — compiler knows this is exhaustive
    };
}
```
