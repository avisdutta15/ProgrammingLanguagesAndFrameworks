# 21. Collections Framework

### Collection Hierarchy

```
Iterable
└── Collection
    ├── List (ordered, duplicates allowed)
    │   ├── ArrayList (like C# List<T>)
    │   ├── LinkedList
    │   └── Vector (legacy, synchronized)
    ├── Set (no duplicates)
    │   ├── HashSet (like C# HashSet<T>)
    │   ├── LinkedHashSet (insertion order)
    │   └── TreeSet (sorted — like C# SortedSet<T>)
    └── Queue / Deque
        ├── PriorityQueue
        ├── ArrayDeque (like C# Stack<T> + Queue<T>)
        └── LinkedList (implements Deque)

Map (NOT a Collection!)
├── HashMap (like C# Dictionary<K,V>)
├── LinkedHashMap (insertion order)
├── TreeMap (sorted — like C# SortedDictionary<K,V>)
├── Hashtable (legacy, synchronized)
└── ConcurrentHashMap
```

### List

```java
// Creation
List<String> list = new ArrayList<>();
List<String> fixed = List.of("a", "b", "c");         // immutable (Java 9+)
List<String> copy = List.copyOf(existingList);        // immutable copy

// Operations
list.add("item");
list.add(0, "first");
list.get(0);
list.set(0, "new");
list.remove(0);
list.remove("item");       // removes first occurrence
list.contains("item");
list.size();
list.isEmpty();
list.indexOf("item");
list.subList(1, 3);        // view (not a copy!)
list.sort(Comparator.naturalOrder());

// Iteration
for (String s : list) { }
list.forEach(System.out::println);  // method reference
```

### Map

```java
// Creation
Map<String, Integer> map = new HashMap<>();
Map<String, Integer> fixed = Map.of("one", 1, "two", 2);    // immutable
Map<String, Integer> entries = Map.ofEntries(
    Map.entry("one", 1),
    Map.entry("two", 2)
);

// Operations
map.put("key", 42);
map.get("key");                          // returns null if absent
map.getOrDefault("key", 0);             // default if absent
map.containsKey("key");
map.containsValue(42);
map.remove("key");
map.size();
map.keySet();                            // Set<K>
map.values();                            // Collection<V>
map.entrySet();                          // Set<Map.Entry<K,V>>

// Modern operations (Java 8+)
map.putIfAbsent("key", 99);
map.computeIfAbsent("key", k -> expensiveComputation(k));
map.computeIfPresent("key", (k, v) -> v + 1);
map.merge("key", 1, Integer::sum);      // increment or set to 1
map.forEach((k, v) -> System.out.println(k + "=" + v));
```

### Set

```java
Set<String> set = new HashSet<>();
Set<String> fixed = Set.of("a", "b", "c");

set.add("item");      // returns false if already present
set.remove("item");
set.contains("item");
set.size();

// Set operations
set1.retainAll(set2);   // intersection (modifies set1)
set1.addAll(set2);      // union
set1.removeAll(set2);   // difference
```

### Queue and Deque

```java
// Queue (FIFO)
Queue<String> queue = new LinkedList<>();
queue.offer("item");   // add (returns false if full)
queue.poll();          // remove head (returns null if empty)
queue.peek();          // view head (returns null if empty)

// Deque (double-ended) — use as stack or queue
Deque<String> stack = new ArrayDeque<>();
stack.push("item");    // push to top
stack.pop();           // remove from top
stack.peek();          // view top

// Priority Queue (min-heap by default)
PriorityQueue<Integer> pq = new PriorityQueue<>();
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Comparator.reverseOrder());
```

### Collections Utility Class

```java
Collections.sort(list);
Collections.reverse(list);
Collections.shuffle(list);
Collections.min(collection);
Collections.max(collection);
Collections.frequency(collection, element);
Collections.unmodifiableList(list);    // read-only wrapper
Collections.synchronizedList(list);    // thread-safe wrapper
Collections.singletonList(item);       // immutable single-element list
Collections.emptyList();               // immutable empty list
```
