# 25. Optional

`Optional<T>` (Java 8+) is a container that may or may not hold a value. It's Java's way to handle nullability explicitly (no null reference types like C# 8+).

```java
// Creating Optional
Optional<String> present = Optional.of("Hello");        // must not be null
Optional<String> nullable = Optional.ofNullable(value); // may be null
Optional<String> empty = Optional.empty();

// Checking and extracting
if (present.isPresent()) {
    String val = present.get();
}
present.ifPresent(System.out::println);
present.ifPresentOrElse(
    System.out::println,
    () -> System.out.println("Empty!")
);

// Default values
String result = nullable.orElse("default");
String result2 = nullable.orElseGet(() -> computeDefault());  // lazy
String result3 = nullable.orElseThrow();                      // throws NoSuchElementException
String result4 = nullable.orElseThrow(() -> new NotFoundException("Not found"));

// Transformation (functional style)
Optional<Integer> length = present.map(String::length);
Optional<String> upper = present.map(String::toUpperCase);
Optional<Optional<String>> nested = present.map(this::findRelated); // oops, nested
Optional<String> flat = present.flatMap(this::findRelated);         // flattened

// Filtering
Optional<String> long_ = present.filter(s -> s.length() > 3);

// Stream integration (Java 9+)
Stream<String> stream = present.stream();  // 0 or 1 element stream

// Practical example
public Optional<User> findUserById(long id) {
    User user = database.query(id);
    return Optional.ofNullable(user);
}

// Caller
String email = findUserById(42)
    .map(User::getEmail)
    .filter(e -> e.contains("@"))
    .orElse("no-email@example.com");
```

**C# comparison:** Optional is roughly equivalent to the nullable reference type annotations + null-conditional operators (`?.`, `??`). Java doesn't have those operators — Optional is the idiomatic alternative.

**Best practices:**
- Never use `Optional` as a method parameter or field
- Use it primarily as a return type for methods that might not return a value
- Never call `.get()` without checking `.isPresent()` first (or use `.orElse*()`)
