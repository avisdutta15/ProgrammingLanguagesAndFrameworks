## 11. Object-Oriented Programming

### Classes

```java
package com.example.model;

public class Person {
    // Fields (instance variables)
    private String name;
    private int age;
    private static int instanceCount = 0;  // static field

    // Constructor
    public Person(String name, int age) {
        this.name = name;   // 'this' same as C#
        this.age = age;
        instanceCount++;
    }

    // Overloaded constructor
    public Person(String name) {
        this(name, 0);  // constructor chaining — like C#'s : this()
    }

    // Default constructor (only exists if you declare NO constructors)
    public Person() {
        this("Unknown", 0);
    }

    // Getter (no auto-properties in Java!)
    public String getName() {
        return name;
    }

    // Setter
    public void setName(String name) {
        this.name = name;
    }

    // Method
    public String introduce() {
        return "Hi, I'm " + name + ", age " + age;
    }

    // Static method
    public static int getInstanceCount() {
        return instanceCount;
    }

    // toString() — like C#'s ToString()
    @Override
    public String toString() {
        return "Person{name='%s', age=%d}".formatted(name, age);
    }

    // equals() — like C#'s Equals()
    @Override
    public boolean equals(Object o) {
        if (this == o) return true;  // same reference? definitely equal (optimization)
        if (o == null || getClass() != o.getClass()) return false;  // null or different type? not equal
        Person person = (Person) o;  // safe downcast — we've confirmed it's a Person
        return age == person.age && Objects.equals(name, person.name);  // compare fields (Objects.equals handles null safely)
    }

    // hashCode() — like C#'s GetHashCode()
    @Override
    public int hashCode() {
        return Objects.hash(name, age);
    }
}
```

**Major difference from C#:** Java has NO properties. You must write explicit getter/setter methods. IDEs generate these for you, or you can use libraries like Lombok or use Records (Java 16+).

### Object Creation

```java
Person p = new Person("Alice", 30);
System.out.println(p.getName());
System.out.println(p);  // calls toString() implicitly
```
### Pass by Value vs Pass by Reference

**Java is ALWAYS pass by value.** There is no pass by reference. However, for objects, the *value being passed is the reference* (memory address) — which confuses many developers.
