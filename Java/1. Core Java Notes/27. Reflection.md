# 30. Reflection

Java's reflection API is similar to C#'s `System.Reflection` — inspect and manipulate types at runtime.

```java
import java.lang.reflect.*;

// Get Class object (like C# Type)
Class<?> clazz = String.class;
Class<?> clazz2 = "hello".getClass();
Class<?> clazz3 = Class.forName("java.lang.String");

// Inspect class
String name = clazz.getName();           // "java.lang.String"
String simple = clazz.getSimpleName();   // "String"
Package pkg = clazz.getPackage();
Class<?> superclass = clazz.getSuperclass();
Class<?>[] interfaces = clazz.getInterfaces();
int modifiers = clazz.getModifiers();
boolean isAbstract = Modifier.isAbstract(modifiers);

// Fields
Field[] fields = clazz.getDeclaredFields();  // all fields (including private)
Field field = clazz.getDeclaredField("value");
field.setAccessible(true);  // bypass private access
Object value = field.get(instance);
field.set(instance, newValue);

// Methods
Method[] methods = clazz.getDeclaredMethods();
Method method = clazz.getDeclaredMethod("substring", int.class, int.class);
Object result = method.invoke(instance, 1, 5);

// Constructors
Constructor<?> ctor = clazz.getDeclaredConstructor(String.class);
Object instance = ctor.newInstance("hello");

// Annotations
if (method.isAnnotationPresent(ApiEndpoint.class)) {
    ApiEndpoint endpoint = method.getAnnotation(ApiEndpoint.class);
    String path = endpoint.path();
}

// Generics (limited due to type erasure)
Type genericType = field.getGenericType();
if (genericType instanceof ParameterizedType pt) {
    Type[] typeArgs = pt.getActualTypeArguments();
}
```

### Dynamic Proxy (like C# DispatchProxy / Castle DynamicProxy)

```java
interface UserService {
    String findUser(long id);
}

UserService proxy = (UserService) Proxy.newProxyInstance(
    UserService.class.getClassLoader(),
    new Class[]{UserService.class},
    (proxyObj, method, args) -> {
        System.out.println("Calling: " + method.getName());
        // actual implementation or delegation
        return "User-" + args[0];
    }
);
proxy.findUser(42);  // prints "Calling: findUser", returns "User-42"
```
