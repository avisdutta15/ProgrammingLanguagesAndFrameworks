# 16. Enums

Java enums are far more powerful than C# enums — they are full classes.

```java
// Simple enum
public enum Direction {
    NORTH, SOUTH, EAST, WEST
}

// Enum with fields, constructor, and methods
public enum Planet {
    MERCURY(3.303e+23, 2.4397e6),
    VENUS(4.869e+24, 6.0518e6),
    EARTH(5.976e+24, 6.37814e6),
    MARS(6.421e+23, 3.3972e6);

    private final double mass;
    private final double radius;

    // Constructor (implicitly private)
    Planet(double mass, double radius) {
        this.mass = mass;
        this.radius = radius;
    }

    public double surfaceGravity() {
        final double G = 6.67300E-11;
        return G * mass / (radius * radius);
    }

    public double surfaceWeight(double otherMass) {
        return otherMass * surfaceGravity();
    }
}

// Enum implementing interface
public enum Operation implements BinaryOperator<Double> {
    PLUS  { public Double apply(Double a, Double b) { return a + b; } },
    MINUS { public Double apply(Double a, Double b) { return a - b; } },
    TIMES { public Double apply(Double a, Double b) { return a * b; } },
    DIVIDE{ public Double apply(Double a, Double b) { return a / b; } };
}

// Usage
Direction d = Direction.NORTH;
Planet earth = Planet.EARTH;
double weight = earth.surfaceWeight(75);

// Enum methods
Direction[] all = Direction.values();           // all values
Direction n = Direction.valueOf("NORTH");       // from string
int ordinal = Direction.NORTH.ordinal();        // 0-based index
String name = Direction.NORTH.name();           // "NORTH"

// Enums work in switch
switch (direction) {
    case NORTH -> moveUp();
    case SOUTH -> moveDown();
    case EAST -> moveRight();
    case WEST -> moveLeft();
}
```

**Key differences from C#:**
- Java enums are objects with methods, constructors, and can implement interfaces
- No underlying integer type by default (you can add one as a field)
- Cannot assign arbitrary int values like `NORTH = 1`
- Each enum constant is a singleton instance

### EnumSet and EnumMap

```java
// High-performance Set for enums (like C# [Flags] but better)
EnumSet<Direction> horizontal = EnumSet.of(Direction.EAST, Direction.WEST);
EnumSet<Direction> all = EnumSet.allOf(Direction.class);

// High-performance Map with enum keys
EnumMap<Direction, String> labels = new EnumMap<>(Direction.class);
labels.put(Direction.NORTH, "Up");
```
