# 3. Basic Syntax and Program Structure

### Hello World

```java
// File: HelloWorld.java
// In Java, the filename MUST match the public class name
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

### Compiling and Running

```bash
# Compile -> Creates a HelloWorld.class file
javac HelloWorld.java

# Run
java HelloWorld

# Since Java 11 — single-file source-code execution
java HelloWorld.java
```

**C# comparison:** Very similar, but Java requires the file name to match the class name. No top-level statements (until Java 21 preview with unnamed classes).

- When we run the javac HelloWorld.java, the compiler transforms your human-readable .java source into .class bytecode that the JVM can execute.

- It's the intermediate format — not machine code, not source code, but something in between that the JVM interprets and JIT-compiles at runtime.

```
_1_HelloWorld.java  →  javac  →  _1_HelloWorld.class  →  java (JVM)  →  runs
    (source)                        (bytecode)
```
**C# comparison:** It's roughly equivalent to a .dll or .exe in C# — the compiled output you ship/deploy. You never edit .class files directly.

We cannot read the .class file. But if we open it using editors like VS Code (and IntelliJ), they will automatically decompile .class files back into readable Java.

### Since Java 21 — Simplified Main (Preview → Finalized in Java 25)

```java
// No class declaration needed
void main() {
    System.out.println("Hello, World!");
}
```

### Packages (Namespaces)

```java
// Packages are Java's equivalent of C# namespaces
package com.example.myapp;

// Import specific class
import java.util.List;

// Import all classes from a package (like 'using' with wildcard)
import java.util.*;

// Static import (like 'using static' in C#)
import static java.lang.Math.PI;
import static java.lang.Math.sqrt;
```

### Naming Conventions

| Element | Convention | Example |
|---------|-----------|---------|
| Package | all lowercase, reverse domain | `com.company.project` |
| Class | PascalCase | `CustomerOrder` |
| Method | camelCase | `calculateTotal()` |
| Variable | camelCase | `orderCount` |
| Constant | UPPER_SNAKE_CASE | `MAX_RETRY_COUNT` |
| Interface | PascalCase (no `I` prefix!) | `Serializable`, `Comparable` |

**Key difference from C#:** Java does NOT prefix interfaces with `I`. `List` is an interface, `ArrayList` is the implementation.

### Comments

```java
// Single-line comment

/* Multi-line
   comment */

/**
 * Javadoc comment — generates documentation (like XML doc comments in C#)
 * @param name the user's name
 * @return a greeting message
 */
public String greet(String name) {
    return "Hello, " + name;
}
```
