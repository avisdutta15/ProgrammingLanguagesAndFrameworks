# 5. Operators

### Arithmetic Operators

```java
int a = 10, b = 3;
a + b   // 13
a - b   // 7
a * b   // 30
a / b   // 3 (integer division — same as C#)
a % b   // 1 (modulus)
```

### Comparison Operators

```java
==  !=  <  >  <=  >=
```

**Critical difference from C#:** `==` on objects compares REFERENCES, not values!

```java
String a = new String("hello");
String b = new String("hello");
a == b      // false! (reference comparison)
a.equals(b) // true  (value comparison)

// String literals are interned, so this works by coincidence:
String c = "hello";
String d = "hello";
c == d      // true (same interned reference) — but NEVER rely on this
```

### Logical Operators

```java
&&  // short-circuit AND
||  // short-circuit OR
!   // NOT
&   // non-short-circuit AND (evaluates both sides)
|   // non-short-circuit OR
^   // XOR
```

### Bitwise Operators

```java
&   // AND
|   // OR
^   // XOR
~   // complement
<<  // left shift
>>  // signed right shift (preserves sign bit)
>>> // unsigned right shift (Java-specific — no C# equivalent operator)
```

### Ternary Operator

```java
int max = (a > b) ? a : b;  // identical to C#
```

### instanceof Operator

```java
// Traditional
if (obj instanceof String) {
    String s = (String) obj;
}

// Pattern matching (Java 16+) — like C# pattern matching
if (obj instanceof String s) {
    System.out.println(s.length());
}
```
