### Inner Classes

```java
public class Outer {
    private int x = 10;

    // Non-static inner class (has reference to Outer instance)
    public class Inner {
        public void display() {
            System.out.println(x);  // can access outer's private members
        }
    }

    // Static nested class (like C# nested class — no outer reference)
    public static class StaticNested {
        public void display() {
            // Cannot access x here
        }
    }

    // Local class (inside a method)
    public void method() {
        class Local {
            void doSomething() { }
        }
    }

    // Anonymous class (like C# anonymous types, but for interfaces/classes)
    Runnable r = new Runnable() {
        @Override
        public void run() {
            System.out.println("Running");
        }
    };
}
```
