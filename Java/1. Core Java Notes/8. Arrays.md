# 8. Arrays

### Declaration and Initialization

```java
// Declaration
int[] numbers;         // preferred style
int numbers2[];        // also valid (C-style)

// Initialization. same as C#
int[] numbers = new int[5];                    // default values (0)
int[] primes = {2, 3, 5, 7, 11};             // array initializer
int[] squares = new int[]{1, 4, 9, 16, 25};  // explicit new + initializer

// Multi-dimensional arrays
int[][] matrix = new int[3][4];        // rectangular (but actually array of arrays)
int[][] jagged = new int[3][];         // jagged array
jagged[0] = new int[2];
jagged[1] = new int[5];
int[][] marks = {
    {1, 2, 3},
    {4, 5, 6}
};

```

**Key difference from C#:** Java has no true multi-dimensional arrays (`int[,]`). All multi-dimensional arrays in Java are arrays of arrays (jagged).

### Array Operations

```java
int length = numbers.length;  // .length (field, not method — no parentheses!)

// Sorting
Arrays.sort(numbers);                          // natural order (ascending)

// Sorting with a custom Comparator (works with Object arrays, not primitives)
String[] names = {"Charlie", "Alice", "Bob"};
Arrays.sort(names, (a, b) -> a.length() - b.length());  // by length: [Bob, Alice, Charlie]
Arrays.sort(names, Comparator.reverseOrder());           // reverse alphabetical
Arrays.sort(names, String::compareToIgnoreCase);         // case-insensitive

// Sorting Integer[] (wrapper array) with custom comparator
Integer[] nums = {5, 2, 8, 1, 9};
Arrays.sort(nums, (a, b) -> b - a);                     // descending: [9, 8, 5, 2, 1]
Arrays.sort(nums, Comparator.reverseOrder());            // same — descending

// Copying
int[] copy = Arrays.copyOf(numbers, numbers.length);
int[] partial = Arrays.copyOfRange(numbers, 1, 4);

// Filling
Arrays.fill(numbers, 0);

// Searching (array must be sorted)
int index = Arrays.binarySearch(numbers, 7);

// Converting to String (for printing)
System.out.println(Arrays.toString(numbers));       // [1, 2, 3, 4, 5]
System.out.println(Arrays.deepToString(matrix));    // [[1, 2], [3, 4]]

// Comparing
boolean equal = Arrays.equals(arr1, arr2);
```

### Varargs (Variable Arguments)

```java
// Like C# params
public int sum(int... numbers) {
    int total = 0;
    for (int n : numbers) {
        total += n;
    }
    return total;
}

sum(1, 2, 3);          // 6
sum(new int[]{4, 5});  // 9
```
