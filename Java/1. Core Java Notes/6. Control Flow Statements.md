# 6. Control Flow Statements

### if / else if / else

```java
if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';
} else {
    grade = 'C';
}
```

### switch Statement (Traditional)

```java
switch (day) {
    case MONDAY:
    case FRIDAY:
        System.out.println("Working hard");
        break;  // fall-through without break (unlike C# which disallows it)
    case SATURDAY:
        System.out.println("Weekend!");
        break;
    default:
        System.out.println("Midweek");
}
```

### switch Expression (Java 14+)

```java
// Arrow syntax — no fall-through, no break needed
String result = switch (day) {
    case MONDAY, FRIDAY -> "Working hard";
    case SATURDAY, SUNDAY -> "Weekend!";
    default -> "Midweek";
};

// With blocks
int numLetters = switch (day) {
    case MONDAY, FRIDAY, SUNDAY -> 6;
    case TUESDAY -> 7;
    default -> {
        String s = day.toString();
        yield s.length();  // 'yield' returns value from block (like C#'s expression-bodied)
    }
};
```

### for Loop

```java
for (int i = 0; i < 10; i++) {
    System.out.println(i);
}
```

### Enhanced for Loop (foreach)

```java
// Like C#'s foreach
for (String item : collection) {
    System.out.println(item);
}
```

### while and do-while

```java
while (condition) {
    // body
}

do {
    // body
} while (condition);
```

### Labeled Breaks and Continues

```java
// Java supports labeled loops (C# does not have this!)
outer:
for (int i = 0; i < 10; i++) {
    for (int j = 0; j < 10; j++) {
        if (j == 5) break outer;  // breaks the outer loop
        if (i == 3) continue outer;  // continues the outer loop
    }
}
```
