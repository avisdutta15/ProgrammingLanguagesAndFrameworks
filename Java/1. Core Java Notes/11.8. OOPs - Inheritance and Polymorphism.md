# 14. Inheritance and Polymorphism

### Inheritance

```java
// Java uses 'extends' (not ':' like C#)
// ALL classes implicitly extend java.lang.Object (like System.Object in C#)
public class Animal {
    protected String name;

    public Animal(String name) {
        this.name = name;
    }

    public void speak() {
        System.out.println(name + " makes a sound");
    }
}

public class Dog extends Animal {
    public Dog(String name) {
        super(name);  // MUST call super constructor if parent has no default constructor
    }

    @Override  // annotation (not 'override' keyword) — optional but recommended
    public void speak() {
        System.out.println(name + " barks");
    }
}
```

**Key differences from C#:**
- Java methods are virtual by default (overridable). C# requires `virtual` keyword.
- Use `final` to prevent overriding (equivalent to C# `sealed` on methods).
- `@Override` is an annotation, not a keyword — it's optional but the compiler checks it.
- No `new` keyword for hiding methods. If you don't use `@Override`, you get hiding.

### Preventing Inheritance and Overriding

```java
// final class — cannot be extended (like 'sealed' class in C#)
public final class ImmutablePoint {
    private final int x, y;
    // ...
}

// final method — cannot be overridden
public class Parent {
    public final void criticalMethod() {
        // cannot be overridden in subclasses
    }
}
```

### Polymorphism

```java
Animal animal = new Dog("Rex");  // upcasting (implicit)
animal.speak();  // "Rex barks" — dynamic dispatch (virtual by default!)

// Downcasting
if (animal instanceof Dog dog) {  // pattern matching
    dog.fetch();
}
```

### The Object Class

All classes inherit from `java.lang.Object` which provides:

```java
toString()      // string representation
equals(Object)  // equality check
hashCode()      // hash code for collections
getClass()      // runtime type info (like GetType())
clone()         // shallow copy (protected, needs Cloneable)
finalize()      // DEPRECATED — do not use (like C# finalizer)
wait(), notify(), notifyAll()  // threading primitives
```
