# 7. Console Output — print, println, and printf

### How `System.out.println` Works

`System.out.println("Hello")` is three things chained together:

| Part | What it is |
|------|-----------|
| `System` | A final class in `java.lang` — cannot be instantiated |
| `out` | A `public static final` field of type `PrintStream` — represents standard output |
| `println()` | A method on `PrintStream` that prints a line and adds a newline |

```java
// Breaking it down:
System.out.println("Hello");

// Equivalent to:
PrintStream output = System.out;   // get the static PrintStream field
output.println("Hello");           // call println on it
```

#### The `System` Class

`System` is a utility class (all static members, private constructor) that provides:

```java
System.out      // PrintStream — standard output (stdout)
System.err      // PrintStream — standard error (stderr) — prints in red in most IDEs
System.in       // InputStream — standard input (stdin)

System.currentTimeMillis()    // current time in milliseconds
System.nanoTime()             // high-resolution timer (for benchmarking)
System.exit(0)                // terminate the JVM
System.getenv("PATH")        // read environment variables
System.getProperty("os.name") // read system properties
System.arraycopy(src, 0, dest, 0, len)  // fast native array copy
System.gc()                   // suggest garbage collection (not guaranteed)
```

#### Why `out` Is Static

`out` is a static field, so you access it via the class name (`System.out`) without creating an instance of `System`. This is by design — there's only one stdout for the entire JVM process.

### `print` vs `println` vs `printf`

#### `print()` — No Newline

Prints the argument and keeps the cursor on the same line:

```java
System.out.print("Hello ");
System.out.print("World");
// Output: Hello World    (all on one line, no trailing newline)
```

#### `println()` — With Newline

Prints the argument followed by a platform-specific newline (`\n` on Unix, `\r\n` on Windows):

```java
System.out.println("Hello");
System.out.println("World");
// Output:
// Hello
// World

System.out.println();  // just prints a blank line
```

#### `printf()` — Formatted Output

C-style formatted printing. Does NOT add a newline automatically:

```java
String name = "Alice";
int age = 30;
double gpa = 3.85;

System.out.printf("Name: %s, Age: %d%n", name, age);
System.out.printf("GPA: %.2f%n", gpa);       // 2 decimal places
System.out.printf("Hex: %x%n", 255);          // "ff"
System.out.printf("Padded: %10s|%n", "hi");   // right-aligned, 10 chars wide
System.out.printf("Left:   %-10s|%n", "hi");  // left-aligned
```

#### Common Format Specifiers

| Specifier | Type | Example | Output |
|-----------|------|---------|--------|
| `%s` | String | `printf("%s", "hi")` | `hi` |
| `%d` | int/long | `printf("%d", 42)` | `42` |
| `%f` | float/double | `printf("%f", 3.14)` | `3.140000` |
| `%.2f` | float (2 decimals) | `printf("%.2f", 3.14159)` | `3.14` |
| `%x` | hex | `printf("%x", 255)` | `ff` |
| `%o` | octal | `printf("%o", 8)` | `10` |
| `%b` | boolean | `printf("%b", true)` | `true` |
| `%c` | char | `printf("%c", 65)` | `A` |
| `%n` | newline (platform-safe) | `printf("hi%n")` | `hi\n` |
| `%%` | literal `%` | `printf("100%%")` | `100%` |

**Use `%n` instead of `\n`** inside `printf` for platform-independent newlines.

### `System.err` — Error Output

```java
System.err.println("Something went wrong!");  // prints to stderr (red in IDEs)
```

`err` is a separate stream — it can be redirected independently from `out` in the shell:

```bash
java MyApp > output.txt 2> errors.txt    # stdout → file, stderr → separate file
```

### Printing Objects

When you pass an object to `println`, it calls `.toString()` on it:

```java
Person p = new Person("Alice", 30);
System.out.println(p);
// Calls p.toString() → output depends on whether you've overridden toString()
// Default (no override): Person@1a2b3c4d  (class name + hash)
// With override: Person{name='Alice', age=30}
```

### Comparison Summary

| Method | Newline? | Formatted? | Use case |
|--------|:--------:|:----------:|----------|
| `print()` | No | No | Inline output, building a line piece by piece |
| `println()` | Yes | No | Most common — one value per line |
| `printf()` | No | Yes | Aligned tables, decimal precision, padding |
