# 2. Setting Up the Environment

### Installing the JDK

The recommended approach is to use a version manager or download from:
- [Adoptium (Eclipse Temurin)](https://adoptium.net/) — community-driven, free
- [Oracle JDK](https://www.oracle.com/java/) — commercial with free dev use
- [Amazon Corretto](https://aws.amazon.com/corretto/) — free, production-ready

### Key Environment Variables

```bash
JAVA_HOME=/path/to/jdk
PATH=$JAVA_HOME/bin:$PATH
```

### Verifying Installation

```bash
java --version
javac --version
```

### IDEs

- **IntelliJ IDEA** — the de facto standard (like Visual Studio for Java)
- **Eclipse** — open source, plugin-heavy
- **VS Code** — with Java Extension Pack
